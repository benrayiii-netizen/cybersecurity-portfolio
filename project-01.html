AI Phishing Detection API

Machine-learning email classification with explainability, risk prioritization, API access, authentication, and logging.

Python Scikit-learn FastAPI Machine Learning Docker

The Problem

Turning suspicious email into prioritized security data

Security analysts must distinguish legitimate email from phishing attempts while processing large volumes of messages. A useful detector must do more than return a binary classification: it should provide confidence, explain why a message was flagged, and help prioritize the result for investigation.

The Solution

An explainable phishing detection pipeline

The project uses a trained machine-learning classifier and text vectorizer to analyze email content. Predictions are enriched with confidence levels, influential text indicators, phishing categories, and severity so the result is more useful in a SOC-style workflow.

Classification

Determines whether submitted email content is phishing or legitimate.

Confidence

Reports model confidence and converts it into High, Medium, or Low confidence levels.

Explainability

Surfaces influential indicators that contributed to the machine-learning prediction.

Prioritization

Adds phishing category and severity information to support analyst triage.

Detection Evidence

Critical credential-theft detection

A test phishing message was classified as phishing with 99.9% confidence. The API identified influential terms including account, click, urgent, suspended, and verify, categorized the message as Credential Theft, and assigned Critical severity.

Model Results

Evaluation and batch-analysis capability

98% Accuracy

Evaluation testing produced approximately 98% classification accuracy.

82,486 Emails

The batch-scanning workflow processed more than 82,000 email records.

43,119 Phishing

The batch workflow classified 43,119 records as phishing in the project dataset.

Explainable Alerts

Predictions include indicators that help explain why content was considered suspicious.

Engineering Lessons

What this project demonstrates

Building the classifier was only one part of the engineering problem. The project evolved into a security service by adding explainability, confidence thresholds, batch processing, SOC-style reporting, API access, authentication, logging, and Docker support.

The result demonstrates how machine learning can be incorporated into a broader detection-engineering workflow rather than treated as an isolated model.

Future Improvements

Where the detector can go next

Future development can include URL and domain reputation enrichment, attachment analysis, improved model evaluation, production-grade secret management, centralized logging, cloud deployment, and integration with the SOC correlation workflow.
