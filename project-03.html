PROJECT 03 • SOC OPERATIONS • ALERT CORRELATION

SOC Alert Correlation Engine

Correlating phishing and authentication alerts into prioritized security incidents with analyst guidance.

Python Pandas SOC Operations Incident Response Correlation

The Problem

Individual alerts do not always tell the full story

Security analysts often investigate alerts from different systems independently. A phishing event may appear moderate in isolation, while a suspicious login may appear unrelated. When both events affect the same user within a short period, however, the combined activity may represent a much more serious compromise.

The Solution

Correlating related security activity into incidents

The correlation engine ingests phishing and suspicious login alerts, compares users and event timestamps, identifies related activity within a defined time window, and creates a consolidated security incident for analyst investigation.

User Correlation

Matches security alerts associated with the same user identity.

Time-Window Analysis

Identifies related alerts occurring close together in time.

Incident Creation

Converts related alerts into one consolidated incident record.

Analyst Guidance

Adds recommended response actions to support investigation and escalation.

Incident Engineering

Turning correlated alerts into analyst-ready cases

Incident ID

Each correlated event is assigned a unique incident identifier.

Severity

Correlated phishing and login activity is prioritized using incident severity.

Case Ownership

Incidents include status and assigned analyst fields to simulate SOC case management.

Recommended Actions

Response guidance includes account, session, mailbox, MFA, sender, and escalation actions.

Correlation Evidence

Two Critical incidents identified

The demonstrated workflow processed three phishing alerts and three suspicious-login alerts. Two related user-event pairs were identified within the configured correlation window and converted into Critical incidents.

Analyst Response

Recommended investigation and containment actions

The correlated incidents provide response guidance including blocking malicious senders or domains, checking MFA status, reviewing sign-in activity, resetting credentials, revoking active sessions, investigating mailbox rules, and escalating the case to SOC Tier 2 when appropriate.

Engineering Lessons

Correlation reduces alert isolation

The project demonstrates that alerts become more useful when analysts can evaluate relationships across multiple security controls instead of treating each signal as an independent event.

Adding correlation logic, incident IDs, case status, ownership, risk scoring, and response recommendations moves the workflow closer to practical SOC incident handling.

Future Improvements

Expanding the correlation engine

Future development can include additional alert sources, configurable correlation windows, MITRE ATT&CK mapping, graph-based relationships, external SIEM integration, automated case escalation, threat-intelligence context, persistence in a database, and AI-assisted incident summarization.
